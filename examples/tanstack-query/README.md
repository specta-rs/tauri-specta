# Tauri Specta Query example

A [`create-tauri-app`](https://github.com/tauri-apps/create-tauri-app) React TypeScript
project with [`tauri-specta-query`](../../crates/tauri-specta-query) wired up. It shows the
generated `queries`, `mutations`, and `queryKeys` helpers being used by TanStack Query.

## Layout

- `src-tauri/src/lib.rs` — the commands, split into a query set and a mutation set for
  `CommandSet`, plus the `UserCreated` event.
- `src/bindings.ts` — generated by Tauri Specta. `cargo test -p
  tauri-specta-example-tanstack-query` regenerates it, as does every `pnpm tauri dev`
  start.
- `src/App.tsx` — `useQuery(queries.listUsers())` and a `useMutation` that invalidates the
  list through `queryKeys.listUsers()`.

## Running

From the repository root:

```sh
pnpm install
cd examples/tanstack-query
pnpm tauri dev
```
