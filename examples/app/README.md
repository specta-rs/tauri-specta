# Tauri Specta example

A [`create-tauri-app`](https://github.com/tauri-apps/create-tauri-app) vanilla TypeScript
project with Tauri Specta wired up. This example covers the setup; see the
[Tauri Specta docs](https://docs.rs/tauri-specta) for everything the library can do.

## Layout

- `src-tauri/src/lib.rs` — the commands, the `Greeted` event, and the `Builder` that
  collects them. `export_bindings` writes the bindings out and `run` starts Tauri.
- `src-tauri/src/main.rs` — a thin entry point that calls `run`.
- `src/bindings.ts` — generated by Tauri Specta. `cargo test -p tauri-specta-example-app`
  regenerates it, as does every `pnpm tauri dev` start.
- `src/main.ts` — calls `commands.*` and listens to `events.*`.

## Running

From the repository root:

```sh
pnpm install
cd examples/app
pnpm tauri dev
```
