# Tauri Specta custom plugin example

A [`create-tauri-app`](https://github.com/tauri-apps/create-tauri-app) Solid TypeScript
project that consumes a Tauri plugin built with Tauri Specta, plus the plugin itself.

The plugin owns its commands and events, exports its own bindings, and is published to the
application as a workspace package — so the frontend imports `addNumbers` and `events`
from `tauri-specta-custom-plugin` rather than from the application's own bindings.

## Layout

- `plugin/` — the Tauri plugin. `plugin/src/lib.rs` registers `add_numbers` and the
  `RandomNumber` event, and `plugin/index.ts` re-exports the generated bindings.
- `plugin/bindings.ts` — generated by `cargo test -p tauri-plugin-specta-example`.
- `app/` — the application hosting the plugin. `app/src/App.tsx` is the only place the
  plugin is used.

## Running

From the repository root:

```sh
pnpm install
cd examples/custom-plugin/app
pnpm tauri dev
```
